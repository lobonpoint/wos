# Incremental roadmap — avoid overbuilding

## Release 0.1 (this ZIP)
Local project registry, approved file import, proposed email actions/projects, Markdown brief, candidate knowledge extraction, tests and five skills.

## Next — evidence and quality
Add tested source-to-project linking, human confirmation of actions, verified outcome capture, FTS search, freshness per workstream, and explicit status change evidence. Validate on synthetic then authorized real examples.

## Reporting skills
- `wos-team`: ingest approved structured weekly updates (project, owner, status date, accomplishments, next week, blockers, decisions needed); draft missing-status requests.
- `wos-manager`: draft a biweekly HTML/PPTX report using only verified registry snapshots, with changes, decisions and risks; human sends.
- `wos-peers`: draft agendas for biweekly peer calls, resolve ownership and cross-team dependencies; capture action follow-ups.
- `wos-architecture`, `wos-devops`: re-use approved governance standards and code-quality evidence as available.

## Only after security approval
Optional classic Outlook local COM collector (Windows only), scheduled ingestion, approved enterprise data connectors, controlled Outlook draft creation, human-approved delivery. No auto-send by default.

## Definition of done for next iteration
100% imported-source traceability; no duplicate project creates without review; verified action transitions; no invented dates/status; measured time saved; clear fail-closed security behavior.
